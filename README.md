## Сборка
Для сборки (`Ubuntu`) необходимы пакеты: `build-essential`, `cmake`, `git`
```
git clone git@github.com:master-gekus/factory_accounting
cd factory_accounting
mkdir build
cd build
cmake -DCMAKE_BUILD_TYPE=Release ../
cmake --build .
cd tests
ctest
```
## Классы
Все классы реализованы в виде шаблонов. Параметр шаблона - класс (структура) с любым набором дополнительных данных для сотрудника (в техзадании этого не было - но надо ж как-то отличать сотрудников).
### Emploee
Абстрактный класс-предок для всех типов работников. Для класса задаётся базовый оклад, относительный месяц приёма на работу и набор дополнительных данных.
Кроме того, класс поддерживает список подчинённых и одного начальника. Классы-наследники отличаются только способом подсчёта реальной зарплаты в конкретный месяц.
Экземпляры классов-наследников нельзя непосредственно создать или уничтожить - для этого используется класс `FactoryAccounting`.
### Worker
Рабочий.
### Foreman
Бригадир.
### Manager
Менеджер.
### FactoryAccounting
Контейнер для хранения и управления экземплярами наследников класса `Emploee`. Позволяет создать (нанять), удалить (уволить) сотрудника, установить или снять подчинение.

## Чего не хватает
- Нет проверки на попытку установки циклического подчинения (типа, A->B, B->C, C->A). Возможно зацикливание расчёта реального оклада при установке такого вида подчинения.
- Не хватает тестов на увольнение подчинённых сотрудников.

## Что можно уличшить
- Добавить кэширование рассчитанной зарплаты.
- Распараллелить по потокам расчёт зарплат подчинённых.
